FAQ

Pertanyaan umum

Siapa yang bisa memakai aplikasi ini?

Guru yang akunnya didaftarkan Admin sekolah. Sekolah yang belum terdaftar dapat mendaftar lewat tombol Daftarkan Sekolah; pendaftar menjadi Admin setelah disetujui.

Apakah perlu API Key?

Ya. Tiap pengguna menghubungkan API Key Gemini pribadinya (gratis dari Google AI Studio) di menu Pengaturan, sehingga kuota tidak dibagi dengan sekolah lain.

Apakah data sekolah lain terlihat?

Tidak. Soal dan kop dipisahkan per sekolah. Guru hanya melihat soalnya sendiri dan soal yang dibagikan di sekolahnya.

Apakah soal bisa diedit dan dicetak ke Word?

Bisa. Setiap butir dapat diedit, lalu diekspor sebagai PDF atau Word (.doc).

Siap menyusun soal berkualitas?

Daftarkan sekolah Anda atau masuk dengan akun guru yang sudah ada.

Cara cepat ambil API Key gratis

  1. Buka Google AI StudioAkses aistudio.google.com/apikey dengan akun Google Anda.
  2. Buat API KeyKlik “Create API key”, pilih atau buat project.
  3. Salin & tempelSalin kunci, tempelkan di kolom sebelah kiri, lalu simpan.

Privasi & keamanan kunci

API Key disimpan di Script Properties proyek Apps Script dan tidak pernah dikirim kembali ke browser (hanya 4 karakter terakhir yang ditampilkan). Pemilik proyek Apps Script secara teknis dapat melihat Script Properties, jadi gunakan kunci khusus aplikasi ini.

Berapa biaya API Key Google Gemini?

Google AI Studio menyediakan paket gratis dengan batas permintaan per menit dan per hari yang dapat berubah. Periksa ketentuan terbaru di situs Google.

Bagaimana jika kuota habis atau error?

Aplikasi mencoba model lain secara otomatis. Jika tetap gagal, tunggu beberapa menit atau pakai API Key lain.

Apakah soal yang saya buat aman?

Soal disimpan di spreadsheet sekolah Anda dan hanya terlihat oleh pembuat serta Admin sekolahnya.
